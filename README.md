# 七域逐鹿 · Java Edition v2.3

> 架空1910年代中华大地 · 28势力文字策略战棋 · Spring Boot 3.2 + Leaflet

**七域逐鹿** 是一款架空1910年代中华大地文字策略战棋。1910年，延续三百年的华夏帝国土崩瓦解，天下陷入混战。从东北雪原到南洋群岛，28路势力（+29 NPC）在340个省份、7个大区中逐鹿争雄。

Java版是Python v2.1的完整移植，增加Phase 1帝国系统、奏折机制、崩溃叙事、全域外交关系、AI全行为系统。

## 快速开始

```bash
mvn package -DskipTests
java -jar target/qiyuzhulu-2.2.0.jar
# 浏览器访问 http://localhost:5000
```

## 游戏系统

### Phase 1：帝国余晖（Java独有）
- 开局全图统一大清帝国（340省），扮演帝国最后的决策者
- 每回合批阅一份奏折（准/驳），共13份（7核心+6紧急）+5份列强贷款
- 帝国收入受崩溃值压制：`income = base × 15% × max(8%, 1-collapse%)`
- 国库耗尽/民心崩溃/腐败蔓延→帝国崩塌→28势力分裂→选择你的势力
- 动态崩溃叙事根据每份奏折的准驳生成具体文案

### 回合制策略
每回合 3 AP，侧栏7部门面板：

| 部门 | 功能 |
|------|------|
| ⚔ 国防 | 募兵、军事行动、当前战争、兵力部署、设计局（自定义战术/兵种） |
| 🏛 政府 | 六维条状图、反腐、税率拉条（农/商）、国魂展示、奏折记录 |
| 🌐 外交 | 27势力列表+关系条+条约状态，互不侵犯/贸易/同盟/宣战/和谈/休战 |
| 🕵 情报 | 侦察敌情、内部维稳、邻区侦察、反间谍 |
| 🏗 建设 | 11种建设（工厂/军校/水利/货币/宣传/遣使/步骑炮工兵） |
| 🔬 科技 | 3层17项科技（工业/农业/军事/海军/思想五大分支） |
| 📜 国策 | 57条国策决议（8条带国魂），分类：可颁布/已颁布/锁定 |

### 战役系统
- 8 种战术：强攻/迂回/炮击/设伏/设防/夜袭/试探/总攻
- 多轮结算：每回合一轮，2-4轮分胜负（不可一回合结束）
- 战中交互：⚙战术调整 📨增援 🏳撤退
- BFS 寻路：地图自动计算可达范围和高亮路径
- 势力覆灭检测+授勋+地块归属

### 地图系统
- 340 省份（100 城市 + 237 郊野 + 1 港口 + 2 关卡），7 大区
- Leaflet 交互地图：缩放/拖拽/右键势力详情
- 动态势力边界 + 驻军标记（绿色玩家/红色敌方）+ 战役标记 + 首都标签
- 增量驻军渲染（消除闪烁），暗色填色（史诗感）
- 省份弹窗：六维数值条 + 铁路/港口 + 资源 + 驻军

### 外交系统
- 全部28势力+NPC间基础外交关系（同区敌对/异区中立/意识形态修正）
- AI间自动签署互不侵犯条约，战役发动时遵守
- 区域内势力关系折叠面板（📊 外交页底部）
- 列强贷款奏折：国库<50触发，批准给对应NPC国魂

### 进化系统
各势力有 3 阶段进化路径。例如：
- 奉天边防军 → 满洲帝国/东北革命根据地/关东自治省
- 国民革命军 → 中华民国/革命根据地/联合政府

### 国家精神（国魂）
- Phase 1 奏折分配国魂（批→政府派正面，驳→反对派补偿）
- 国策颁布获得国魂（8条：迁都定鼎/总动员令/精锐卫队/焦土令等）
- 列强贷款→NPC获得列强支持国魂
- 政府面板实时显示当前国魂

### AI 系统
AI 势力每回合自动：
- ✅ 收入/维持费/补给
- ✅ 招募部队
- ✅ 移动部队（向边境推进）
- ✅ 发动战役（找目标/评估战力/创建战役）
- ✅ 外交互不侵犯（AI间自动签署，关系>15时10%/回合）
- ✅ 国策颁布（20%/回合）
- ✅ 地块建设（15%/回合）

### 调试工具

- 🔄 切换势力：随时切换控制任意势力
- 🔍 DOM检查 / 🌐 全局变量 / 📋 弹窗测试 / 🚚 移动测试

## 项目规模

- Java: 44文件 · ~10,000行
- 前端: 9 JS + 1 HTML + 1 CSS · ~8,000行
- 数据: game_data.json (28+29势力) · map_data.json (340省) · resolutions.json (57国策) · events.json (11事件)
